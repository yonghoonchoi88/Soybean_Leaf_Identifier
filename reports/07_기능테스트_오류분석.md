## 2. 오류 이력

| 오류 ID | 현상 | 원인 | 조치 | 재검증 |
|---|---|---|---|---|
| E-01 | `docker: command not found` | 사용 중인 Ubuntu-22.04에 WSL Integration 꺼짐 | Docker Desktop WSL Integration 활성화 | `docker --version` 성공 |
| E-02 | `permission denied ... docker.sock` | user1이 docker 그룹 미포함 | `usermod -aG docker` + WSL 재시작 | `docker info` Server 정보 출력 |
| E-03 | `[Errno 98] Address already in use` | 다른 Uvicorn이 8000 포트 점유 | 기존 프로세스 종료 | 서버 정상 기동 |
| E-04 | `python3.11: not found` | Ubuntu 22.04 기본 Python 3.10 | `uv venv --python 3.11` | `python --version` 3.11 |
| E-05 | `No module named pip` | uv 가상환경은 pip 미포함 | `uv pip install` 사용 | 패키지 import OK |
| E-06 | `config.py` SyntaxError | 숫자 뒤 `s` 오입력 | 오타 삭제 | import 성공 |
| E-07 | `dataset/val` 0장 | validation 폴더명 미변경 | `dataset/val`로 이동 | 44/45/44 확인 |
